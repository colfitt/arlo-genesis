# Teletone Audio (suite)

**Summary** — Two **Kontakt Player libraries**: **Scarbo** (cinematic hybrid
synth, ~$89, ~600 MB, Kontakt/Player 5.8+) and **Electro** (vintage
drum-machine beatmaker, ~$129, ~1 GB, Kontakt/Player 6.7.1+, activated via
Native Access). Both run in the owned **Kontakt 8** (full), AU/VST3/AAX via
the Kontakt shell.

## Why I have it
Teletone's house sound is **warm, played-in, tape-adjacent sources** — dirt
baked into the *source* instead of (only) added downstream, which is exactly
this rig's "recorded-wrong" aesthetic. **Scarbo** is a cinematic
texture/drone synth bed to sit under banjo/baritone — the designed-hybrid
pole next to the Spitfire evolving-string walls. **Electro** is the lo-fi
**drum-machine source** (808 / 909 / LinnDrum / DFAM samples, plus Juno-60 /
SK-1 / DX7 synth color) — the vintage-beatbox counterpart to Addictive
Drums 2's acoustic kits, and chop fodder for the MPC / Digitakt.

## Signature uses
- **Scarbo — two-knob sound design:** the whole interface is a **MOOD** knob
  (character) + **MOVEMENT** knob (LFO/scripted animation) — automate MOVEMENT
  up across a section for an evolving bed without touching a mod matrix.
- **Scarbo — Multis** (layered patches) for instant wide hybrid walls; bounce
  a held progression and PaulStretch/degrade it like the Spitfire beds.
- **Electro — Beatmaker as sketchpad:** 100+ factory beats with 7 keyswitched
  variations each; swing + humanize for the drunk-drummer feel; pitch/mod
  wheel mangle the beat live.
- **Electro — blend-your-own kick/snare** (sample blending), then **multi-out**
  per drum into the degrade chain (DS-10 → RC-20 → SketchCassette) — crush
  hats/room, keep the kick clean, same doctrine as AD2.
- **Electro — one-shot factory:** bounce blended hits → MPC Sample / Digitakt 2
  / Kontakt chop material (optionally RC-20-stamped first).

## Notes
- **Player libraries, not plugins** — both work in the free Kontakt Player
  (no full-Kontakt requirement); add/activate through Native Access; they
  mount in the Kontakt library browser.
- **Scarbo v1.3** doubled the instrument content with newly recorded samples
  (free update — check Native Access for the current version).
- **Electro's palette is sampled hardware** (TR-808, TR-909, LinnDrum, Moog
  DFAM; Juno-60, Casio SK-1, DX7) — warmer/more organic than ROMpler drum
  plugins; it's a *source*, so degradation still happens downstream per the
  division-of-labor rule (don't double-degrade).
