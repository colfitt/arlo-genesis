# Eventide Octavox

**Summary** — **8-voice diatonic pitch-shift harmonizer** plugin built on
Eventide's Harmonizer® processor tech (H8000-era Octavox). Pick a key/scale,
place up to 8 voices on a **notation grid** (a music-staff step display —
each voice gets a pitch interval *and* a rhythmic position), with per-voice
pan, level, delay, detune, and feedback. ~$49 (list $99); AU/VST2/VST3/AAX,
64-bit, **iLok account required** (machine authorization, no dongle needed).

## Why I have it
The **in-the-box counterpart to the H90's pitch side** — the same Eventide
diatonic-harmonizer DNA, but recallable, automatable, and printable on stems
after the fact. Fills two rig holes at once: **intelligent in-key harmonies**
for banjo/baritone leads (the H90 does this live; Octavox does it in the mix),
and the classic **Eventide micro-pitch widener** (detuned voices hard-panned)
for shoegaze wall-thickening without another modulation pedal pass.

## Signature uses
- **Micro-shift widener:** two voices at unison, ±5–15 cents detune, panned
  hard L/R, ~10–20 ms delay offset — the studio vocal/guitar thickener, here
  for baritone walls and drone beds.
- **In-key harmony stack** on a banjo/baritone lead: key-locked 3rds/5ths/octaves,
  each voice slightly delayed and spread — a choir out of one performance.
- **Staircase / trailing-melody textures:** voices stepped up the notation grid
  with tempo-synced delays + feedback → cascading arpeggio ghosts; 100% wet on
  a send into Valhalla for self-generating harmonic washes.
- **Sub-octave heft:** a −12 voice tucked under the baritone for doom weight
  without re-amping.

## Notes
- **Diatonic = set the key** (Key Lock holds key/scale across preset changes);
  **MixLock** holds wet/dry while auditioning presets. **Snapshots** store up
  to 32 scenes for section-to-section harmony changes.
- **Pitch tracking is monophonic** — for chords/rhythmic material, disable
  tracking mode (it can stay musical as a fixed shifter); single-note sources
  track best (good news: banjo/baritone lead lines).
- **Randomization** adds micro pitch drift per voice — the "human choir"
  smear; ships with 70+ presets.
- macOS 10.14+ / Windows 10+; 64-bit only (VST2 still shipped).
