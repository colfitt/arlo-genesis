02

The review

Measured against your own v1 plan and against the dream, not against generic repo hygiene.

What’s genuinely strong

  • Schema discipline at scale1,069/1,069 patches carry frontmatter, typed controls, and sources. Referential integrity is near-perfect. Most hobby corpora rot; this one validates.
  • Provenance cultureSignature vs. factory vs. designed vs. community is tagged on every patch. Chunks carry citation targets. This is exactly what keeps a future ARLO from confidently making things up.
  • The blooping engine is real infrastructureNot notes about agents — working workflows with staging guards, human gates, adversarial verification, and lessons learned written into the code. Layer 2 corrected layer 1. That loop is rarer than the data.
  • Rig truth, including failuresThe guides record what was confirmed working and when, and preserve the paths that failed. That honesty is load-bearing for automation later.
  • The Ableton corpus already knows your ceiling63 files including Lite-specific traps: 8 tracks, 2 sends, no Max for Live, which downloadable racks won’t load. The lane-builder direction can be planned against facts you already own.

Where it’s cracked

  • criticalThe engine still doesn’t existYour own v1 plan’s Phase 1 — a root CLAUDE.md persona + 4 skills — was never shipped. There is no CLAUDE.md in this repo. All 3,286 files are currently a library with no librarian.
  • highHalf the control plane is unmapped25 devices are midi: true; only 12 have CC charts. The missing 13 include all four rig brains — VG-800, Octatrack, Digitakt 2, 61SL MkIII — plus Big Sky, TimeLine’s siblings, OP-1 Field. CC charts are the API docs for the dream; the queue already ranks them.
  • highPatches speak human, not machineOnly 43 of 1,069 patches mention a CC number. Values are written for hands: “~40%”, “slightly below noon”, “dotted-8th, clock-locked”. Nothing today can compile a patch into a MIDI message.
  • mediumRig drift: the new rig outran the corpusThe rig map and guides lean on the MC6 Pro (the floor brain sending scenes to nine pedals!), Loopy Pro, Yamaha S08, SM57s, the ADA8200 — none of which have gear/software folders. Loopy Pro is now a central looper with zero corpus presence.
  • mediumThe index is stalechunks.jsonl was last built 2026-06-15; patches changed after. Three promotion files sit staged in research/_promotions/, never appended. Drift is small (1,065 vs 1,069 patches indexed) but the habit matters once retrieval is live.
  • lowSmall hygieneOne chain gear-ref typo; 243 MB of PDFs in git (fine for now, consider LFS if it doubles); v1 docs still point at old /Users/cfitt/Dev/Pedalxly paths.
03

The dream, decomposed

“Think of a patch → Claude builds it across everything I own → lanes appear in Ableton.” That’s one sentence and five subsystems. Here is each one, with its honest status today.

1 · Intent
“Radiohead Ful Stop, for synth.” Taste profile, artist sources, album corpus — the reference knowledge exists and is chunked.
2 · Retrieval
4,672 chunks with provenance… and no index, no MCP server, no search. Today it’s grep or nothing.
3 · Design
Proven by hand — 1,069 patches, 85 chains, the Ful Stop bed itself. Not yet reproducible on demand because stage 1’s engine (persona + skills) is unbuilt.
4 · Compile
Knob-words → CC numbers → 0–127 values. Doesn’t exist. This is the missing middle of the whole dream.
5 · Deliver
Four delivery arms, below. One is green today.
exists & works data exists, engine doesn’t doesn’t exist yet
Hardware via MIDI
Chase Bliss pedals are fully CC-addressable — every knob has a CC, so a compiled patch can literally be pushed and the Big Time’s motorized faders will move. Blocked only by the compiler + the 13 missing CC charts.
Ableton lanes
Create/name/color tracks, set tempo, build the Cold-wire-style session skeleton. Feasible via a remote script (AbletonOSC) or by generating .als files (gzipped XML). Must budget for Lite: 8 tracks, 2 sends, no M4L.
VST presets
The hardest arm. Preset formats are per-vendor and mostly opaque. Realistic near-term: precise settings-sheets per plugin (you own the manuals + research); true preset files later, starting with open formats.
Manual patch sheets
Already works — the Guides prove the format (H90 step-by-steps, studio sheets). ARLO generating these on demand is purely a stage-1 problem.
The one-sentence diagnosis: you have world-class knowledge and zero actuation. Every direction below is either “finally build the librarian” or “grow the corpus a hand.”
04

Directions you can go

Six directions, deliberately composable. A → B → C → D is the straight line to the dream; E and F branch off it.

DIR A

Ship the librarian

Execute your own Phase 1: a root CLAUDE.md (persona, data map, own-only rule, citation rule) plus 4 skills — gear-lookup, chain-design, software-pick, song-skeleton. The acceptance test is already written in v1/02: ask for a washed-out ambient chain, get owned-gear-only with a real citation, no pasting.

Effort: 1–2 sessionsUnlocks: literally everything else
DIR B

Finish the control plane

Bloop the 13 missing CC charts — the queue already ranks them, and the VG-800’s parameter guide PDF is on disk (extraction, not hunting). While you’re there, close the rig drift: MC6 Pro, Loopy Pro, S08, SM57 folders. The MC6 is your scene brain and has zero corpus presence.

Effort: ~8 bloops over a few weeksUnlocks: C and D at full rig width
DIR C

The patch compiler

Patch schema v2: each control gains optional cc: and a normalized 0–127 value alongside the human phrasing. A small script joins a patch against its device’s CC chart and emits a MIDI message list. Start with the Chase Bliss family — six pedals, charts captured, fully CC-addressable.

Effort: a weekend of sessionsUnlocks: patches become executable objects
DIR D

The hands — a MIDI bridge

A tiny local MCP server on the Mac (mido/rtmidi): send_patch(device, patch) streams the compiled CCs out USB/DIN. First demo: say “give me Ful Stop” and watch the Big Time’s faders physically move. Second: build_session(plan) talks AbletonOSC to lay out lanes from a Songs/ plan.

Effort: small server + bench testingDepends on: C (and B for full width)
DIR E

Ableton, two ways

Path 1: AbletonOSC remote script — live control, no M4L needed, should sit inside Lite. Path 2: generate .als session templates directly from song plans (Cold-wire’s plan is already structured enough to compile: tempo 138, 9 sections, named lanes, per-track routing from the rig map). Decide here whether Lite’s 8-track cap is a constraint to design within or the reason to upgrade to Standard.

Effort: one spike each, then pickUnlocks: “it creates the lanes for the song”
DIR F

Pocket ARLO

The “bigger” part. Near-term and cheap: compile chunks.jsonl into a searchable patch-browser artifact — every patch, chain, and guide on your phone, today, no server. Mid-term: ARLO as a remote-reachable MCP so claude.ai on the iPad retrieves from the real corpus. Far: the iPad joins the control plane — network MIDI is native to iPadOS/macOS, and Loopy Pro has deep MIDI bindings.

Effort: browser artifact ≈ 1 sessionUnlocks: patches off the computer
